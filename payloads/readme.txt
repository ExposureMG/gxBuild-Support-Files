Folder to store payloads common to all build versions.

files that can be placed here:
-------------------------------
xell_1f.bin	    - XeLL build for jtag (1f) images
xell_2f.bin	    - XeLL build for jtag (2f) images
xell_gggggg.bin - XeLL build for gg images

freeboot.bin    - FreeBoot binary for jtag rebooter
fuses.bin       - Virtual Fuse File
payload.bin     - Payload for jtag exploit
